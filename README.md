# Airline Management System

A simple Airline Management System built using Java.

## About

This project is a Java-based application developed to practice object-oriented programming and application development concepts.

## Features

* Manage airline-related information
* Handle flight and passenger details
* Perform basic management operations
* Simple and easy-to-understand project structure

## Technologies Used

* Java
* Maven
* Spring Boot

## Getting Started

### Prerequisites

* Java JDK
* Maven

### Run the Project

Clone the repository:

```bash
git clone https://github.com/AnandakrishnanVB/Airline-Management-System.git
```

Open the project in your preferred Java IDE and run the application.
